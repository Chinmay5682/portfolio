## ⚡ Highlights

* **Ambient 3D Live Wallpaper:** Full-viewport WebGL particle system and geometric meshes that dynamically glide and calculate parallax coordinates from cursor positioning and scroll progression.
* **Interactive 3D Stage:** Draggable icosahedron core bounded by dual torus orbital rings, supporting real-time rotation physics for mouse and touch interactions.
* **Typewriter Narrative Subtext:** Automated typewriter engine cycling through current roles, technical specializations, and learning pursuits with a synchronized blinking accent cursor.
* **Typographic Legibility:** Strict z-index stack ensuring written content maintains complete contrast and clarity over active background canvas animations.
* **Zero-Build Architecture:** Runs natively in any browser with zero bundlers, compilers, or `node_modules` overhead.
